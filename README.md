# Yum-Go Food Delivery App

A beautiful, modern Android application for food delivery built entirely with Jetpack Compose. 

## 📥 Try the App (No coding required)
If you just want to test the app on your Android phone, you don't need Android Studio!
1. Go to the **Releases** section on the right side of this GitHub page.
2. Download the `Yum-Go.apk` file to your Android device.
3. Tap the file to install it (you may need to allow "Install unknown apps" in your phone settings).
4. Open the app and enjoy!

## 🛠️ For Developers (Source Code)
If you want to view or edit the source code:

**Prerequisites:** [Android Studio](https://developer.android.com/studio)

1. Clone this repository to your computer.
2. Open Android Studio.
3. Select **Open** and choose the downloaded project folder.
4. Allow Android Studio to sync Gradle and build the project.
5. Click the green "Run" button ▶️ to run the app on an emulator or a physical Android device.
